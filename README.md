# Pembuat Invoice

Alat invoice gratis untuk penjual online. Buat invoice dari orderan WhatsApp, Instagram, Shopee, Tokopedia, Lynk.id, dan lainnya.

- Katalog produk (harga terisi otomatis)
- Daftar pesanan dengan filter status: Belum dibayar, DP, Lunas
- Cetak atau simpan PDF
- Kirim ringkasan invoice ke WhatsApp pembeli
- Cadangan dan pemulihan data

Semua data tersimpan di browser pengguna (localStorage). Tidak ada server dan tidak ada data yang dikirim ke pihak lain.

## Pasang di GitHub Pages

1. Unggah `index.html` ke repo.
2. Buka Settings, lalu Pages.
3. Pilih branch `main` dan folder `/ (root)`, lalu Save.
